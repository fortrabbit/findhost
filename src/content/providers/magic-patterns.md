Magic Patterns generates a UI design from a prompt, a product requirement or an imported Figma file, and lets a designer or engineer iterate on it inside a canvas workspace. A "publish" feature puts a project at a Magic Patterns URL, and the [custom domain documentation](https://magicpatterns.com/docs/documentation/get-started/custom-domain) describes pointing a domain at that URL with a DNS record. There is a public MCP server for pulling design context into an engineer's own tools.

**Listed as a stub.** What is unresolved is whether that published output is a hosted application in the sense this register tracks, or a design prototype shown at a URL — the custom-domain documentation frames it as "your Magic Patterns design," and nothing on the site states that a published project can run backend logic or hold data. Pricing and public documentation both exist without a login, so criteria 3 and 4 hold; what is open is criterion 1, and that is a call for a person rather than for this record.
