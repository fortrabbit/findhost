Hypernode is a Dutch platform built for Magento and Shopware, descended from Byte's engineering and now part of team.blue. It publishes extensive documentation, a deployment tool built on Deployer, PHP and Python API clients, a Docker development environment and n98-magerun plugins.

The pricing page renders its figures client-side, so no plan price can be read without JavaScript — which is why criterion 3 still has to be checked by hand here.
