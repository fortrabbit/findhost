Windsurf was an AI-assisted code editor with `windsurf.build`, a feature for deploying an app built inside it to a live URL. Cognition, which also builds the Devin agent, acquired it. Per Cognition's own [Devin Desktop FAQ](https://docs.devin.ai/desktop/devin-desktop-faq), Windsurf was renamed Devin Desktop on June 2, 2026: "the same IDE, same editor, and has the same features, but unified under the Devin brand."

**Criterion 2 — sold to the public — fails, because nothing is sold under this name.** `windsurf.com` now redirects to Cognition's `devin.ai/desktop`, and `windsurf.build` redirects the same way; there is no page left describing Windsurf on its own or pricing it separately from Devin Desktop. The one exception is existing Windsurf Enterprise accounts, which the FAQ says keep signing in at `windsurf.com/enterprise` — a legacy path for customers who already had one, not a new purchase.

Recorded here rather than dropped because the name is still what a search for it turns up, and it is useful to be able to see where it went. Cognition has a record here, and is the entity that now sells what Windsurf sold.
