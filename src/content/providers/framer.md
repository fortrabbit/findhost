Framer is a visual site builder that publishes what it designs. A design canvas, a content model and the hosting are one product, so there is no deployment step and no server to reach: a site goes live from the editor. The work it is sold for is landing pages, portfolios and company sites.

Paid tiers add custom domains, staging and larger content models; a free tier publishes on a Framer subdomain. Developers extend sites with custom React components and a public API rather than by running code of their own on the platform.
