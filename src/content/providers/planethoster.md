PlanetHoster is a Franco-Canadian host operating data centres in Paris, Lausanne and Montreal, letting a customer pick the location per project — unusual at its price point. It sells "Web Projects" rather than accounts, on its own N0C panel, with PHP 5.6 to 8.5, Python, Node.js and Ruby documented and a public knowledge base covering SSH, Composer, cron and databases. Criteria 1 to 5 pass cleanly.

**Criterion 6 — two independent artifacts — could not be satisfied.** Searched: GitHub repository and code search in French and English, and the acme.sh and lego DNS provider registries. Integration libraries do exist — planethoster-php, planethoster-node, planethoster-ruby, an API client and two WHMCS modules — but every one of them is published by PlanetHoster itself, and first-party work does not count.

This is a well-documented platform with a genuinely multilingual runtime story, and the rejection rests entirely on who wrote the tooling. **A framework integration guide, a third-party package, an independent talk or an issue-tracker thread would be enough to list it.**
