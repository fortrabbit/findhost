Afrihost is a South African ISP whose headline products are fibre, wireless, mobile and VoIP, with shared hosting as one line among many. Linux plans support PHP, Perl, MySQL, PostgreSQL and CGI, the help centre documents changing PHP version through cPanel, and billing is month-to-month with no contract. Criteria 1 to 5 pass.

**Criterion 6 — two independent artifacts — could not be satisfied.** Searched: GitHub repository and code search, the acme.sh and lego DNS provider registries. What surfaced was a defunct code-camp API from 2019 and unrelated projects that happen to share the name.

The shape of the company explains some of this: a consumer ISP with a hosting line attracts customers rather than integrators, and the help centre is oriented at panel tasks rather than at developers — no Node.js or Python support is documented at all. **A framework integration guide, a third-party package, an independent talk or an issue-tracker thread would be enough to list it.**
