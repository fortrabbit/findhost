EvenNode is a managed hosting platform for Node.js and Python applications, operated by Adhouse, s.r.o. from Bratislava, Slovakia. An application is deployed by git push or FTP; the platform runs it across a set of managed processes behind a load balancer, and a three-member MongoDB replica set with a free SSL certificate is provisioned alongside every plan.

Plans are a fixed monthly fee that scales with process count, memory and storage, from a small tier up to a named custom tier for larger workloads. Billing is monthly with no minimum term, prices are shown in EUR exclusive of VAT, and cancellation takes effect immediately with no refund for the current period.

## Worth knowing

An application can be launched without a card, but continued use beyond that requires upgrading to a paid plan. EvenNode's own pages describe server locations only as "Europe and the United States," without naming specific countries or regions.
