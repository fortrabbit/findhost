Boomla is a web application platform built around its own language and an object-oriented composition model, where a page is assembled by placing objects inside other objects. It includes a visual designer, a built-in database and server-side rendering, and the [Boomla language reference](https://lang.boomla.app/) and the Turbo CSS documentation describe the pieces a developer would work with.

**Criterion 2 — sold to the public — fails.** The current site's only path in is [Request demo](https://boomla.com/request-demo), and that page itself says "Sorry, we are unable to schedule demos at this time." There is no self-serve signup, no pricing page and no login link on the home page or the docs entry point. An earlier version, Boomla v1, was free and self-serve, but its own page marks it discontinued; the product now offered at boomla.com has no purchase path at all as of this check.

**This reverses if boomla.com opens a self-serve signup or the demo form starts accepting requests again.**
