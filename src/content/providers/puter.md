Puter is a browser-based desktop environment: signing in gives an account cloud file storage, a set of built-in apps, and the ability to publish a static site to a subdomain of puter.site. The same codebase is also published on GitHub, described there as "Free, Open-Source, and Self-Hostable," so the same software can be run on a person's own server instead of on Puter's hosted instance.

**Criterion 3 — public pricing — fails on the hosted instance at puter.com.** Every account gets a storage, database and AI allowance at no charge, and Puter's own [pricing FAQ](https://developer.puter.com/pricing/) says a user who exceeds it "pays Puter directly for the extra," but no page states what that costs. The pricing page at puter.com itself renders no plan or price without signing in.

**This reverses if Puter publishes a price for usage beyond the free allowance without requiring a login.**
