## About SpinupWP

SpinupWP is a [server management service](/category/server-management/) specifically designed for WordPress. It connects over SSH to servers at [DigitalOcean](/provider/digitalocean/), [Linode](/provider/linode/), [Vultr](/provider/vultr/), [Hetzner](/provider/hetzner/), [AWS](/provider/aws/), [Google Cloud](/provider/gcp/) — any Ubuntu server it can reach — and configures a stack tuned for WordPress. It was built by Delicious Brains, the original makers of WP Migrate; after that plugin business went to WP Engine in 2022, SpinupWP became the company's sole product.

It sits in the middle ground between a system administrator and a managed WordPress host: a control panel to manage servers and sites, while the underlying infrastructure account stays the customer's responsibility.

### What SpinupWP does well

- **WordPress optimization**: The stack is standard, unmodified server software tuned for WordPress performance (Nginx, PHP-FPM, Redis object caching).
- **Developer tools**: Site cloning, staging environments and WP-CLI support are built in.
- **Cost**: Can be cheaper than fully managed hosting for those comfortable owning the server relationship.
