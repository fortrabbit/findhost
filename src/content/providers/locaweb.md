Locaweb is the anchor brand of LWSA, a Brazilian technology group listed on the B3 exchange, hosting a stated 500,000-plus sites. Shared plans run PHP with a documented version switcher, SSH is enabled from the panel in three-hour windows on Linux plans, and prices are published in reais. Criteria 1 to 5 pass.

**Criterion 6 — two independent artifacts — could not be satisfied.** Searched: GitHub repository search and code search in Portuguese and English, the acme.sh DNS provider list, and the lego provider registry. Everything that exists under the Locaweb name is published by Locaweb's own GitHub organisation — a CSS framework, a payment-gateway plugin, style guides — and first-party work does not count.

Its sibling brand KingHost, on the same group infrastructure, does pass: a community WHMCS module and an acme.sh DNS driver both exist for it. That asymmetry is real rather than an artefact of searching, and it is worth noting that Locaweb has no published API, CLI or infrastructure-as-code path for anyone to build against in the first place. **A framework integration guide, a third-party package, an independent talk or an issue-tracker thread would be enough to list it.**
