Radicle is an open-source, peer-to-peer code collaboration stack built on git, with issues and patches stored as signed git objects and no single operator of the network, as its [homepage](https://radicle.dev/) describes. Radicle Garden is the paid service beside it: a node that stays online and copies the repositories a user chooses, so they remain reachable while the user's own node is not, and that also serves static sites from a repository branch. It adds to a local node rather than replacing one. The [terms](https://radicle.garden/terms) name Monadic Works GmbH in Berlin as the contracting party, and the [help pages](https://radicle.garden/help) describe the operator as owned by The Better Internet Foundation.
