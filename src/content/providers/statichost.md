statichost.eu is operated by Variable Object Assignment, a company registered in Stockholm and [founded in 2022](https://www.statichost.eu/about/) by Eric Selin. It hosts static sites and nothing else. A build platform clones any repository that `git clone` can reach, runs the build inside whatever Docker image a `statichost.yml` file in the repository names, and publishes the output directory to an edge network of the provider's own. A site can also be created from a zip file uploaded in the dashboard, through a bash CLI script, or through a [JSON API](https://www.statichost.eu/docs/api/) that is marked beta.

The free Hobby plan holds one site. The paid plans add unlimited sites, larger bandwidth and build-minute allowances with a metered overage above them, staging as a second site, team seats and a wider CDN. What the provider sells on is where it runs and what it keeps: every layer is said to run on European providers with no US cloud anywhere in the stack, the CDN is [provided by acache.io](https://www.statichost.eu/faq/), and visitor IP addresses are held in memory to answer a request and never written to a log, which the [privacy policy](https://www.statichost.eu/privacy/) and a published DPA both state. Which providers those are, and in which countries, the site does not say.

## Worth knowing

The [terms](https://www.statichost.eu/terms/) describe the service as in beta testing and provided on a best-effort basis without warranty. A service level agreement is offered only by contacting the company to set up a paid account. Overage is not enforced by a hard limit: the [FAQ](https://www.statichost.eu/faq/) says a site that exceeds its quota keeps being served and its owner is contacted to set up payment.

Preview links for branches and pull requests are [on the roadmap](https://www.statichost.eu/roadmap/) and not available. The documented workaround is a second site built from the other branch. An API key acts as the whole user, with no per-site or read-only scope.
