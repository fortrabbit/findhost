CodeSandbox sells isolated cloud sandboxes, described on its own home page as "sandboxes built for scale" that let a customer "programmatically spin up isolated sandboxes for instant code execution in your AI agents and code playgrounds." A sandbox is a virtual machine that code runs in, resumable from a snapshot, and a preview of a running one is served at a `csb.app` address. The company trades as CodeSandbox BV, and its own footer names it "a Together AI company."

**Listed as a stub because only the home page could be read.** The pricing page, the documentation and the company pages all answered a request with 403 on the day this record was made, so what is sold, at what price, and whether a finished app can be kept at a stable address are all unconfirmed. The scope question behind this record — a development sandbox against a place an app is deployed to — turns on those pages, and it is left open rather than decided from marketing copy.
