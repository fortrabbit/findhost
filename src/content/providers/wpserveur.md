WPServeur is a French host that accepts WordPress sites and nothing else, with SSH, WP-CLI and git access, per-site PHP configuration, one-click clones and centralised plugin updates across sites. Plans are metered by number of sites, storage and monthly visits, and prices are published in euros. It sponsors WordCamps in Paris, Lyon and Marseille.

**Criterion 6 — two independent artifacts — could not be satisfied.** Searched: GitHub repository and code search in French and English, the WordPress plugin directory, and the acme.sh and lego DNS provider registries. One qualifying artifact was found: a migration plugin for the platform maintained by BlogVault, a third party. Its best-known open-source contribution, the widely installed WPS Hide Login plugin, is WPServeur's own and does not count.

Worth recording alongside the rejection: the legal notice identifies WPServeur as part of the CELESTE group and names a sister company as the hosting provider, so the infrastructure is not its own. **A second independent artifact would be enough to list it.**
