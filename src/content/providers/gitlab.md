GitLab sells the hosted version of software anyone may also install: issues, merge requests, CI runners, a container registry and a package registry in one application. The free plan on gitlab.com is permanent; Premium is $29 per user a month billed annually, with compute minutes included and more purchasable, which is the plan-and-meter shape the pricing field records.

## Worth knowing

The self-hosted edition is why this record is about gitlab.com only. Running the same software on a server bought elsewhere is a different arrangement with a different bill, and the fields here would all be wrong for it.

No code of a customer's runs on this service, so runtimes, deploy methods and shell access are not applicable. Regions are not offered as a choice on gitlab.com either.

[GitLab Pages](/gitlab-pages/) serves a built site from a repository and is recorded separately, as a static host.
