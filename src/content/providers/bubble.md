## About Bubble

Bubble is a no-code platform for building full web applications: a visual editor for the UI, a workflow engine for the logic, and an integrated database. Founded 2012 in New York, it is popular for prototypes, internal tools, and early-stage products, because a first version ships without an engineering team. The trade-off is structural: Bubble apps run only on Bubble's infrastructure, and the application logic cannot be exported as code — data comes out via CSV or API, the app itself does not. Outgrowing the platform means a rebuild.
