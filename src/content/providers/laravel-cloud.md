## About Laravel Cloud

Laravel Cloud is a service somewhere between [PaaS](/category/paas/) and [vanity hosting](/category/vanity-hosting/). It's made by Laravel Holdings Inc. and thus an official part of the Laravel ecosystem. In 2024 Laravel announced $57M in funding; Laravel Cloud reached general availability in early 2025.

Laravel Cloud is a PaaS-like solution in the tradition of early platforms like Heroku. It started Laravel-only and has since added Symfony support — other PHP frameworks and plain PHP are not supported. The entry plan costs $0 plus usage, so the actual monthly bill depends on metered compute, database and bandwidth. It ships advanced features such as scale-to-zero hibernation, autoscaling and preview environments.

## Reservations

- Usage-based pricing makes the monthly bill hard to predict
- Classic access paths like SSH and SFTP are not part of the workflow
- Only Laravel and Symfony apps run there — other PHP code is out
- Autoscaling and scale-to-zero are rarely hard requirements for agency projects
- Another vendor-specific platform to learn, on top of the framework
