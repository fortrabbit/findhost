anynines is a German company selling platform software and managed data services: a9s Cloud Foundry, a9s Data Services, Klutch, and licensed database services for PostgreSQL, MariaDB, MongoDB and others, run on the customer's own VMs, Kubernetes, cloud account or hardware.

**Criterion 2 — sold to the public — is not satisfied.** There is no signup and no self-service purchase; the site asks for a demo booking, and no price appears for any product. Criterion 3 fails on the same page for the same reason.

It is recorded rather than ignored because anynines ran a public Cloud Foundry platform for years and is still the name some people search for when they mean European PaaS. What it sells now is software and operations for teams who already have somewhere to run them, which is a different product from the one this register lists. Somebody buying a place to put an application is not the customer here.
