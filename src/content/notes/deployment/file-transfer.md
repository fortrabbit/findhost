File transfer is publishing by copying: change a file, send it, it is live. It works everywhere, needs no build step and is the reason a great deal of the web is running code nobody can reproduce, since the server is the only copy. SFTP runs over SSH and is the safe form of it; plain FTP sends the password in the clear and is still offered, which is a fact about the market rather than a recommendation.
