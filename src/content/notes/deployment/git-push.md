Pushing to the platform is the oldest of the modern deployment methods and still the fewest parts: no external account, no webhook, no integration to authorize. The repository can live anywhere or nowhere. What it needs is somewhere for the build to happen, which is why platforms offering it usually detect the stack and run the install themselves.
