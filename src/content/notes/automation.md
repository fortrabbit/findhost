description: Which providers can be driven by something other than a browser — a public API, a command-line tool, or an MCP server.
lead: Whether the platform can be operated by something that is not a person.
---

Three ways in, and a provider can offer any combination. An **API** makes the account programmable at all. A **CLI** is the same capability shaped for a terminal and for scripts, and is usually what a deployment pipeline reaches for. An **MCP** server exposes the platform to language models directly, which is new enough that very few providers have one.

This facet is derived rather than recorded: each value reads a field on the record, so the detail — whether a CLI is official or third-party, whether an API is public or partner-only — stays on the provider's own page where the distinction means something. A ticked box means the thing is documented. An unticked one is not a claim that it is absent, only that nothing has been recorded.
