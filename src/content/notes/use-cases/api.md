description: Hosting marketed for API backends — no pages to cache, and latency measured by the client rather than a person.
lead: Nobody is looking at it.
---

An API backend has no HTML to cache and no patient human in front of it: every request reaches the application, and the caller is code that will retry. That puts the emphasis on consistent latency, connection limits and a database that keeps up, rather than on page caching or a CDN. Providers marketing it usually mean regions close to the callers and an easy path to more instances.
