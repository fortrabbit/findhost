description: Hosting marketed for web apps — an application with users, sessions and background work rather than pages.
lead: An application, not a site.
---

A web app is software that happens to be reached through a browser: it has accounts, state, a database and often work that continues after the response is sent. That last part is what separates the hosting — queues, scheduled jobs and a second process type. Providers marketing themselves here are usually application platforms rather than site hosts.
