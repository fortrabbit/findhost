Most AI applications are ordinary web applications with an unusual request shape: a call to a model API that takes seconds, a response streamed to the browser, and timeouts tuned accordingly. The expensive part is the model provider's bill, not the hosting. Where a provider means GPUs rather than that, it is a different product entirely — this dataset records web hosting, so read the category before assuming inference is included.
