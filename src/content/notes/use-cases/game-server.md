description: Hosting marketed for game servers — persistent processes, raw ports and latency that players notice.
lead: Not a web workload at all.
---

A game server holds open connections, often over UDP on non-standard ports, and its quality is measured in milliseconds to the player. That rules out most web hosting, which serves HTTP on two ports and optimizes throughput rather than latency. Providers marketing it mean a machine or a container with direct network access, chosen for where the players are.
