description: Ghost hosting — a Node.js application, which rules out most of the shared hosting that runs a CMS.
lead: A Node app, not a PHP one.
---

Ghost is [Node.js](/runtimes/node/), and that single fact excludes most of the hosting built for CMS work. It needs a process kept alive, a database, and somewhere for uploaded images — closer to hosting an application than publishing a site. Providers here are the ones that run long-lived Node processes, plus Ghost's own hosted service. A PHP shared host will not run it however many installers it offers.
