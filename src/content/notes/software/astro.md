description: Astro hosting — static output almost everywhere, with an adapter where server rendering is needed.
lead: Static by default, server where asked.
---

Astro produces static files by default, which makes it the easiest of the JavaScript frameworks to host: any static host serves it, including a CDN with no runtime at all. On-demand rendering needs an adapter matched to the platform, and that is the only part where hosting choice constrains anything. This register runs on it.
