Umbraco is a .NET CMS, which narrows the field: it needs a [.NET](/runtimes/dotnet/) runtime and SQL Server or SQLite, so a Linux PHP host is out. Current versions run in Linux containers, but most providers naming it sell Windows plans or a managed cloud of their own. Media lives on disk or in blob storage, and the database is the part to size.
