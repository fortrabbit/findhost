Craft is commercial software installed through Composer, so hosting it means a build step, a database, and somewhere to put uploaded assets that a deploy will not wipe. The providers documenting it are mostly the ones selling to agencies, since that is who buys the licenses. A plain PHP host will run it; the ones named here have written the guide.
