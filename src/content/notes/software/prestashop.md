PrestaShop is a PHP shop with [MySQL](/databases/mysql/) behind it and a module ecosystem that stretches a host: a cron job for stock and mail, and enough memory for the back office. The image cache grows with the catalog, so disk matters more than for a blog. A provider naming PrestaShop has a one-click installer or a plan sized for it; the [e-commerce](/use-cases/e-commerce/) list is the wider view.
