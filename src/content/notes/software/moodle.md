Moodle is a PHP learning platform with a database, a data directory that must sit outside the web root, and a cron job it cannot do without: grades and notifications run on it. Term start is the load test, hundreds of logins in the same hour. A provider naming Moodle has sized a plan for that peak or sells a managed instance. The [learning](/use-cases/learning/) list shows who else serves that audience.
