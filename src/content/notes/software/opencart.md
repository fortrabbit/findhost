OpenCart is a lighter PHP shop than [PrestaShop](/software/prestashop/) or [Magento](/software/magento/): a [MySQL](/databases/mysql/) database, an extension directory the store owner writes to, and modest memory. It runs on [shared hosting](/categories/shared-hosting/) and ships in control-panel installers, which is how most providers support it. The payment modules available for a region decide more than the host does.
