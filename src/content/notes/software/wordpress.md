Almost every provider runs WordPress. Vanity WordPress hosting means caching in front, updates applied by the host, staging without a database export, and a plan for the day the site is compromised. Everyone else is running [PHP](/runtimes/php/) and MySQL and leaving the rest to a plugin. WooCommerce is here rather than under a name of its own, because the shop is a plugin. What changes is the load: cart and checkout cannot be cached, so every visitor reaches PHP and the database on a site that would otherwise be mostly static.
