---
description: Hosting for Django — providers that document the framework itself, not just the Python underneath it.
lead: Python hosting that admits it runs Django.
---

Any host running [Python](/runtimes/python/) can run Django, so appearing here means something narrower: the provider documents the framework by name, with a guide, a template or a one-click install. That usually implies the parts Django needs beyond a web process — a database, static file collection at deploy time, and somewhere to run management commands. A host listing Python but not Django will serve the application and leave the deployment steps as an exercise.
