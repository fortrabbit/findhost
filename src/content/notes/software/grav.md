Grav is a flat-file PHP CMS: content lives in Markdown and YAML files, and there is no database to provision. It needs PHP with a writable user directory and a cache directory it can write to, so almost any [PHP](/runtimes/php/) host qualifies, [shared hosting](/categories/shared-hosting/) included. A provider naming it has written an installer or a guide; the rest can run it without saying so.
