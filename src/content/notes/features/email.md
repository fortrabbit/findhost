Shared hosts have run mail alongside websites for as long as there have been shared hosts, and often still do. Application platforms almost never do: sending mail from a container is a deliverability problem rather than a feature, and the usual arrangement is a separate mail provider on the same domain. Recorded as included only where mailboxes come at no extra charge.
