Everything else in this register is a fact we found. This is an opinion we hold, and it is the only one in the dataset. It began as a scoring system that added up favorable features and let a person move the total by hand; after eighteen adjustments the arithmetic was decoration, so it became a boolean somebody sets deliberately. Each record marked here gives its own one-line reason, and the reasons do not agree with each other — some are innovative, some are small and deserve to be found, some have simply behaved well for a long time. There is no opposite box: "the ones we did not pick" would be a verdict on two hundred companies nobody passed, and absence here means only that nobody chose it. Ticking this changes what is shown and never the order, which stays alphabetical. [Our own service](/fortrabbit/) is in the list, which is the [bias disclosed](/about/) rather than removed.
