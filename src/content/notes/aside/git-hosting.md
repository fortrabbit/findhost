Almost every record in this register can deploy from a git commit, and almost none of them keeps the repository. That is what these companies sell: a forge, with the reviews, issues and CI that grew around it. Nothing of a site runs here, so the hosting rows read as not applicable rather than unknown. A host that deploys from a commit answers this from its own side, as [git deployment](/deployment/git/), which is the question people actually filter on — not where the commit is kept, but whether pushing one is enough to publish.
