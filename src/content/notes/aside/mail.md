Shared hosts have run mail beside websites for as long as there have been shared hosts. Application platforms almost never do — sending mail from a container is a deliverability problem rather than a feature — so a site on a modern platform usually means a second company holding the mailboxes. This marks the ones that sell that. Whether a host includes mail with the hosting is [a separate question](/features/email/), and for most of the register the answer is that it does not.
