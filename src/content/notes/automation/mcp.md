Model Context Protocol servers let an agent operate a platform the way a person would: create an app, read the logs, work out why a deploy failed. Very few providers have one, so this is the thinnest column in the register and the one most likely to change. Whether it is official or a community project is recorded on each page, and for something this young the difference is substantial.
