.NET runs on Linux and has for years, but hosting for it stayed concentrated with the providers that served the Windows era plus the large clouds. The set of hosts documenting it is smaller than the set that could technically run it, which is why the field records what is documented rather than what is possible. Where .NET is listed, deployment is usually a published build or a container image.
