Scala runs on the JVM, so the hosting question is the Java one: enough memory for the heap, and a plan whose price reflects it. Almost no provider markets Scala specifically, which is why the count here is small — a host listing Java will generally run a Scala build without mentioning it, and deployment is a jar or a container either way.
