description: Hosting that runs Java — JVM applications, their memory floor, and the plans that can actually accommodate one.
lead: The JVM has a floor, and it is not low.
---

A JVM application starts by reserving memory, and the smallest hosting plans do not have enough of it. That, more than language support, is what decides whether Java is practical somewhere: a provider may list it and offer no plan with the headroom for a Spring Boot service under load. Deployment is usually a jar or a container. Where Java appears alongside enterprise support tiers, the pricing usually reflects the audience rather than the runtime.
