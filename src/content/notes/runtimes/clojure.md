---

Clojure compiles to JVM bytecode and hosts like any other JVM application, which is exactly why so few providers name it. The count here reflects marketing rather than capability: a host documenting Java support will run an uberjar without comment. Where it is named, it usually signals a platform that lists runtimes generously rather than one doing anything special for the language.
