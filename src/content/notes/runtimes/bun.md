lead: New enough that support is the story.

Bun is recent, and the number of hosts documenting it is small. Where it is not listed, a container image is usually the way in, since Bun ships as a binary and asks little of the host beyond permission to run. Support here means a provider has said so in its own documentation, which for a runtime this young is a more meaningful signal than it would be for PHP.
