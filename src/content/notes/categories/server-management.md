Server management is an odd category. Most providers in this section sell no hosting at all. The product is a software layer to provision web servers. Server management also matches nearly all records in [bring your own infrastructure](/metal/). The account at the hosting provider stays with the customer and the panel connects to it. The bill will mostly have two parts, a subscription plus server costs. An [entry price band](/entry-price/) in this category prices the panel alone. Responsibility splits too: The operating system stays with the customer with a panel to make it manageable, which is why "you, with panel" is the usual answer to [who manages the operating system](/operating-system/) here. A panel automates the routine and can patch unattended. There are the classic control panels, like [cPanel](/cpanel/) and [Plesk](/plesk/) that are licensed per server and are often used with [shared hosting](/categories/shared-hosting/). Then there are developer-facing provisioners like [Laravel Forge](/laravel-forge/), [Ploi](/ploi/), [RunCloud](/runcloud/) and [Coolify](/coolify/) with a feature set that is closed to [PaaS](/categories/paas/). A few resell the infrastructure as well and return one bill, which makes them hard to tell from a PaaS from outside.
