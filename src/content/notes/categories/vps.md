A Virtual Private Server is an empty machine with root. The provider keeps the hypervisor and the network running; everything above that belongs to the customer, which is why these records answer "you" to [who manages the operating system](/operating-system/) and offer [full SSH access](/shell/). It is one of the cheapest ways to run something in [somebody else's data centre](/metal/), and the empty box then has to be kept full — patches, backups, monitoring, the 3am outage — none of which appears in the monthly price. The advertised specifications are softer than they look, too, since hosts are oversubscribed and identical vCPU counts differ in real throughput. [PaaS](/categories/paas/) hands the operating system back; a [management panel](/categories/server-management/) keeps the server and automates the routine.
