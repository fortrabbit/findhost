A site is built inside the product — a visual editor, or lately a prompt — rather than written and deployed, with hosting, templates, updates and certificates included. That is what makes a site possible in an afternoon and what puts the runtime out of reach: no deploy step, so usually no [shell](/shell/) and nothing to record under [software](/software/), because the platform is the runtime. The cost is portability, since a site leaves as content at best. Whether the prompt-built end stays a category of its own turns on one thing: a platform that hands over a git repository is a builder attached to hosting, and one that keeps the code is a page builder with a better interface.
