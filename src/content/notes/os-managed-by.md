description: Who patches the operating system — the customer, the customer with a control panel, the provider, or nobody because the unit is an image.
lead: The one question that settles most category arguments.
---

Categories blur because vendors blur them. This field does not: somebody has to apply the security updates, and there are only four answers. **You** is a machine with root and a sysadmin job attached. **You, with panel** is the same machine with a control panel automating the routine parts. **Provider** means the operating system is not the customer's concern at all. **You, image** means the unit of deployment is a container, so what is patched is a rebuild rather than a running host.

It is the most useful field in the dataset for the same reason it is the least exciting: it stays answerable whatever a provider decides to call its product. Read together with [whose hardware it runs on](/hardware/), it identifies almost any platform here without reference to its marketing.
